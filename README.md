# uzkeyboard-mac

A macOS keyboard layout for Uzbek Latin script. Based on standard US QWERTY with Uzbek-specific characters accessible via the Option (Alt) key.

## Installation

### 1. Download

Go to [Releases](../../releases) and download the latest `uzkeyboard-mac.zip` file. Unzip it to get the `Õzbek Lotin.bundle` file.

### 2. Copy to Keyboard Layouts

Copy the bundle to the system keyboard layouts folder:

```
/Library/Keyboard Layouts/
```

Or for the current user only:

```
~/Library/Keyboard Layouts/
```

### 3. Enable the keyboard

Log out and log back in (or restart your Mac). Then open **System Settings → Keyboard → Input Sources**, click **Edit…**, then **+**, find **Uzbek** in the language list and add **Õzbek Lotin**.

## Usage

The keyboard works exactly like a standard US QWERTY layout. To type Uzbek-specific characters, hold down the **Option** key:

| Character | Shortcut |
|-----------|----------|
| ş | Option + s |
| Ş | Option + Shift + S |
| ğ | Option + g |
| Ğ | Option + Shift + G |
| õ | Option + o |
| Õ | Option + Shift + O |
| ç | Option + c |
| Ç | Option + Shift + C |
